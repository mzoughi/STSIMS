How it works: the source emits light polarized vertically. Filter 1 passes only the component along its own axis (I₁ = I₀cos²θ₁), rotating that light to its own axis direction. Filter 2 then only passes the component of that light along its axis (I₂ = I₁cos²(θ₂−θ₁)).
Try this: set Filter 1 to 0° and Filter 2 to 90° — crossed filters, no light gets through. Now slide Filter 1 to 45° without touching Filter 2. Light reappears, even though the outer two filters are still crossed at 90° to each other. Inserting a filter between crossed polarizers can unlock transmission — the classic "three‑polarizer paradox."
